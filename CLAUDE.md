@AGENTS.md

Read `AGENTS.md` and `docs/agent-operations/OPERATING-STANDARD.md` at session start and after context compaction. For GTA/PC work, read `docs/agent-operations/GTA-PC-PLAYBOOK.md` before any action, plus the current named-owner handoff.

Do not assume this Claude interface has terminal/Windows capabilities, that a different agent's desktop session is yours, or that an API tool is available. Prefer a verified supported command route; when unavailable, prepare a bounded handoff for the named operator instead of clicking arbitrary UI or bypassing approvals. Agent roles derive from the current handoff, not a hardcoded product name. Never execute simultaneously with the live P2 owner.

Read the current PR head and raw correlated evidence before continuing; use `docs/agent-operations/PR-LESSONS-20261023.md` for recurring failure patterns. A successful response from a command is not in-game acceptance.
