Exact original-key delivery survives later speech failure; failed/unfinished reasoning consumes no grant. Assistant history and PS6/PS5 acknowledgement remain independent. This closes its automated oracle; physical acceptance remains separate.

T63 is verified by the direct active-ledger fetch-start/final-result traces plus existing preview/prepare/pruning one-shot delivery fixtures. T65 now has direct terminal acknowledgement evidence: success/exhaustion in all three request modes, plus refusal, incomplete, invalid-shape and invalid-JSON rejection. Retries preserve bytes and produce no intermediate terminal acknowledgement; only the original exact keys receive the final outcome.

T39 is verified by the existing ten-pin test and the new five-pin tie-order fixture: importance/private-ID order, unselected record omission, identical output under reversed source order, and no private memory metadata in either serialized request schema.
