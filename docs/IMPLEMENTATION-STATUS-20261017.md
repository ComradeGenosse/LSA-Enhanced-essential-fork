## How to read

- **Source** = actual code path exists (a JSON/contract row alone is "prepared", not an executable handler).
- **Main** = integrated into current canonical main; source may still be off/experimental.
- **Offline** = scoped CI/test/source-build evidence reported in a cited PR or historical receipt; not automatically rerun at this SHA.
- **GTA** = recorded physical behavior, tied to the version/test described. "Partial" is not a blanket acceptance of latest main.
- **Gate** = missing work or acceptance. If the test outcome is uncertain, it stays open. Check source switches and installed hashes before using any enabled-feature language.
