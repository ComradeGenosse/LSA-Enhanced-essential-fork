- \`lsa-essential-e1-candidate/src/context/knowledgeDelivery.mjs\`: \`createKnowledgeDelivery\` gains \`opinionCurrent\` and \`pruneOpinion\`. Unknown/stale P2 opinion sources fail closed, just as recall does. Only **unsent** optional contributions may be pruned; \`beforeRequest\` on sent provider retries, \`success\` and asynchronous invalidation abort stale revisions.
