## Configuration and behavior

Add `"memoryK": {"profile":"storage-only"}` to an explicit OpenAI/P1/promoted-character configuration with `promotedCharacters.enabled:true` and `storageMode:"sqlite"`. `examples/memory-k-storage-only.json` shows the fields; retain the user's real worldProfileId/paths and approved native contracts when applying it. JSON remains the normal default. This preset requires a restart; it is not a live backend switch or downgrade/export tool.

The existing #160 normalizer expands the preset from its existing descriptor catalog: every optional `memory.*` and `events.*` consumer is explicitly off, including M2, M3/coverage/grace, foreground journal/M4/M5/M8, M6/M7, inspector and M9 callbacks/producers. Consumer on/shadow overrides and unknown profiles are rejected. Other ordinary perception/ACT/Essential settings remain independent; this profile does not enable them. No registry/dependency graph is recreated.

Bootstrap checks the versioned C enforcement prerequisite **before allocating storage/channels/consumers**. On accepted pre-C #138 it throws `storage_only_composition_unavailable`; there is no silent legacy activation. With C, the single existing shared-brain SQLite store initializes and retains migrations, durability, timeline/privacy/source fences. Startup failure remains explicit (`p2_sqlite_startup_failed`) and performs cleanup. No second writer or JSON fallback is introduced. No schema, migration, store authority, privacy or recovery code changes in E1.

Ordinary profiles/manual memories and the existing character editor keep their current storage behavior. Storage-only does not create M3 sinks, optional workers or callbacks and does not run dialogue capture or combined foreground memory preparation. Independent D02/host/world subscriptions may remain when ordinary source collection is explicitly configured; their existence is not authority to write memories. Source-required timelines remain suspended until genuine source plus explicit confirmation; reopened data or a profile preset cannot grant that authority.
