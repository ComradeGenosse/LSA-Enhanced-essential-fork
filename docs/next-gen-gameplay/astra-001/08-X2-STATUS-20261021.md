# X2 implementation checkpoint — NOT ACCEPTED

Original 3 × 2.5 × .2 m concrete wall authored in Blender 5.2.2 / Sollumz 2.9, with 30 chunks, 31 fragment groups, individual collision bounds, GEN9 YFT and Dynamic YTYP. Original assets and an Onigiri pack are included under `native/fragment-x2`. The existing X1 SHVDN lab, probes, file bridge and telemetry were extended. Claude's shutdown helper is preserved; launch, deployment and collection helpers are reusable. No custom physics framework or X3/X4 work was introduced.

The final rocket geometry sampled root movement up to .006 m and face displacement .011 m; after walking the maximum face displacement was .014 m, within the .02 m anchor threshold. All 48 swept spheres remained blocked; the 120-cell face mask remained blocked. Nine nearby props were observed but none carried explicit native detached-parent evidence, so they are not accepted as wall debris. The ped walked around the edge; this is recorded as `bypassed_edge`, never as traversal through a hole. The physical variant uses the engine's fixed joint to a frozen, collision-disabled stock anchor, with a dynamic wall.

No run has combined anchored surviving structure, localized native fragment removal, native debris, a swept collision opening and direct ped traversal. Three-launch repeatability and the 20-blast GO matrix remain unfulfilled. A fundamental engine/export limitation has NOT been proven; further native fragment/group authoring diagnostics are needed before drawing that conclusion.
